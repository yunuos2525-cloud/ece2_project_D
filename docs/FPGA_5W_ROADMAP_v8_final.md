# FPGA 담당 5주 개발 로드맵 · v8

> 프로젝트: **FPGA–STM32 기반 미지의 단일 협대역 간섭 자동 추적·억제 시스템**  
> 담당: FPGA 개발 · RTL/시뮬레이션 · 실물 신호처리 경로 · LCD/시계/스톱워치  
> 연동 기준: [`TEAM_SPI_INTERFACE_v8_final.md`](TEAM_SPI_INTERFACE_v8_final.md)

## 1. 시스템 목표 및 범위

- **입력 조건:** 16 kHz, mono, 초기 8-bit 샘플. 시험용 정상 신호는 500 Hz를 기본으로 하고, **미지의 단일 협대역 간섭** 하나를 더한다.
- **간섭 주파수:** 사전 지정 후보 없이 주파수를 추정한다. 초기 탐색 시험 범위는 **700~3,000 Hz**이며, 실제 적용 범위와 신호 세기는 W1 검증에서 확정한다.
- **핵심 기능:** 간섭 주파수가 변해도 STM32가 다시 추정하고, FPGA가 **그 주파수에 맞게 필터를 갱신**해 출력을 지속한다.
- **신호처리 방식:** STM32가 FFT와 가변 Notch **계수 계산** 담당. FPGA는 **실제 샘플별 IIR Notch 연산** 담당.
- **모드:** STM32가 `BYPASS / FIXED / AUTO`를 요청하고 FPGA가 실제 출력 경로를 전환. `FIXED`는 1 kHz 고정 Notch, `AUTO`는 STM32가 보낸 유효한 가변 계수 사용.
- **공통 필수:** FPGA에서 디지털시계(연·월·일·시·분·초·요일)와 스톱워치(경과 시간). FPGA 스위치로 **LCD 표시 화면** 선택. LCD 화면을 바꿔도 음향 처리는 계속 수행.
- **범위 제외:** 간섭 2개 동시 제거, 후보 주파수 LUT 선택, 사용자 임계값 조절 UI, 음악·음성 품질 보장, 상세 상태 로그 UI.

## 2. 담당 범위·실제 인터페이스

| FPGA가 직접 수행 | STM32가 수행 — FPGA 입장에서 기대하는 것 |
|---|---|
| ADC에서 샘플을 연속 수집하고 DAC로 출력 | 샘플 블록을 읽어 주파수를 추정 |
| 실시간 처리 경로와 별개로 FFT 분석용 **512샘플 블록**을 보관 | 512개 데이터를 올바른 순서로 수신 |
| SPI Slave에서 **MISO로 샘플 블록 송신**, MOSI에서 명령·계수 수신 | SPI Master로 샘플 요청, 모드 및 계수 전달 |
| 전달된 **고정소수점 계수 5개**를 검증된 형식으로 받고 안전한 시점에 일괄 적용 | FFT 결과로 계수를 계산·정해진 형식으로 전송 |
| BYPASS, 1 kHz FIXED, AUTO의 출력을 정확히 전환 | 실제 DSP 모드 선택 |
| 시계·스톱워치·LCD, 스위치 디바운스/모드 전환 | 담당하지 않음 |

**중요:** STM32의 FFT 결과를 기다리는 동안 FPGA의 ADC→DSP→DAC 데이터 경로는 멈추지 않는다. 이전에 적용된 필터는 계속 동작한다. `AUTO`에 들어갔지만 아직 정상 계수를 받지 못한 상태는 BYPASS로 처리한다.

### 구현·검증 기준

- ADC·DAC·샘플 타이밍·SPI의 검증된 기본 모듈은 재사용하고, 새 인터페이스는 단위 시험 후 결합한다.
- **512샘플 블록 버퍼, MISO 응답, 다중 바이트 계수 수신, 가변 IIR Notch**를 기능별로 검증한다.
- 단순 모드 변경이나 시뮬레이터 실행 성공은 실제 간섭 감쇠의 증거가 아니다. 필터 효과를 입력 조건별 예상값과 파형·실측값으로 검증한다.

## 3. 5주 개발·검증 일정

실험실 사용 시간: **주 1회 × 4시간**. W1~W2에 기능 개발과 모듈 시험, W3에 보드 통합, W4~W5에 성능 검증 및 최종 안정화를 배정한다.

| 주차 | 개발·시뮬레이션 | 실험실 검증 | 완료 기준 |
|---|---|---|---|
| **W1 · 기초+위험 요소 선검증** | 기존 샘플링/BYPASS 재사용. **고정 1 kHz IIR Notch**와 검증 TB 제작. 분석용 **512샘플 버퍼+SPI 읽기 경로** 설계/시뮬레이션. 스톱워치/시계 기본 시간 카운터 착수 | ADC→DAC BYPASS 실제 파형, **STM32 PA6 ↔ FPGA BDIO03(G8) MISO 물리 연결·송수신**, 필요 시 LCD 시험 출력 | 고정 Notch 시뮬레이션에서 1 kHz 감쇠·500 Hz 보존 확인. 샘플 버퍼 송신 TB PASS. **MISO 실물 경로 검증 여부 기록** |
| **W2 · 핵심 모듈 완료** | **가변 IIR Notch** 및 고정소수점 계수 입력/원자적 교체, BYPASS/FIXED/AUTO 모드, SPI 수신 패킷 검증. 시계·스톱워치·LCD 표시 모드/날짜 경계 검증. STM32가 보내는 모의 계수로 주파수별 DSP 시뮬레이션 | 실제 **샘플 블록 전송**과 고정/가변 Notch의 첫 보드 출력 측정, LCD 공통 기능 확인 | 임의 시험 주파수(예: 930·1,370·1,830·2,460 Hz)에 맞춘 계수로 FPGA 필터가 시뮬레이션에서 감쇠. 샘플 블록과 계수 패킷의 송·수신 성공 |
| **W3 · 자동 추적 실물 통합** | STM32 실측 FFT 결과로 받은 계수 반영, 필터 전환 시 튐·고정소수점 오류 수정 | 입력 간섭 주파수 변경 → STM32 재추정 → FPGA 새 필터 적용 → 오실로스코프 출력 확인. 세 DSP 모드와 LCD 표시 전환 | **미지의 단일 주파수 간섭을 실제 보드에서 자동 추적·억제**하고, 원인별 실패 로그 확보 |
| **W4 · 성능·디버깅** | 재현된 문제 수정 위주, 신규 필수 기능 금지 | 감쇠량·정상 성분 손상·변경 반응 시간·샘플 누락·재시작 반복 측정 | 측정표·파형·원인/수정/재검증 기록 완성 |
| **W5 · 최종 안정화** | 최소 수정, 최종 버전 동결, 보고서/발표/영상 정리 | 시연 처음부터 재현, 결함 회귀 시험, 누락된 증거 보완 | 실측 결과와 제출 자료가 일치하는 최종 시연 가능 |

### 일정 게이트(무리한 확장 방지)

- **W1:** 실제 ADC/DAC 및 **MISO 송수신 실물 시험**이 가장 큰 위험. MISO 핀 배정은 STM32 PA6 ↔ FPGA BDIO03(G8)로 확정했다. MISO 경로를 확인하지 못한 경우 양방향 통신을 완료로 판정하지 않는다. 팀이 승인한 대체 샘플 취득 방식 없이는 W2 통합 계획을 그대로 강행하지 않는다.
- **W2:** FPGA 가변 Notch 및 STM32 FFT/계수가 **각자 독립 검증되지 않았으면** W3 보드에서 합치는 데 시간을 전부 쓰지 않는다. 각 기능의 실패 원인부터 분리한다.
- **W3:** 자동 추적이 불안정하면 간섭 2개 확장·추가 UI 기능을 시작하지 않는다.
- **W4~W5:** 신규 필수 기능 추가 없이 정량 측정과 재검증에 집중한다. 변경 시 BYPASS/FIXED/AUTO 회귀 시험을 실시한다.

## 4. 필수 시험과 예상 결과

| 시험 조건 | 사전 예상 및 확인할 증거 |
|---|---|
| **BYPASS:** 500 Hz만 입력 | ADC/DAC 파형이 설정된 스케일·지연 범위에서 유지되는지 측정 |
| **FIXED:** 500 Hz + 1,000 Hz | 1,000 Hz 성분 감소, 500 Hz 보존. 우선 시뮬레이션 후 오실로스코프 측정 |
| **AUTO:** 500 Hz + 미지의 간섭 930 / 1,370 / 1,830 / 2,460 Hz 중 하나 | FPGA는 해당 계수로 필터를 적용, 제거 주파수 변화가 출력에 반영되는지 비교 |
| 주파수 930 → 1,830 Hz로 변경 | STM32 새 추정/계수 수신 후 새 Notch가 적용되는지 확인; **추적 반응 시간** 기록 |
| SPI 샘플 블록 손실·중복·전송 중단 | 블록 번호/수신 길이/오류를 식별하며 **오디오 출력은 멈추지 않음** |
| 잘못된 계수·전송 중단 | 불완전 패킷은 필터에 적용하지 않고 이전 유효 계수 유지 |
| 시계/스톱워치 경계 | 59→00, 날짜/월/연도·윤년·요일, START/STOP/RESET과 LCD 화면 독립 확인 |

**측정 목표(성과 주장 아님):** 간섭 감쇠 ≥10 dB, 정상 신호 손상 ≤1 dB, 입력→출력 경로 지연 ≤20 ms. **주파수 재추정 후 필터 갱신 시간은 별도 측정**하며 20 ms와 혼동하지 않는다. 강도·주파수 추정이 잘 되는 입력 조건을 먼저 기록해야 한다.

**검증 방법:** 테스트벤치 예상값 → 파형 비교 → 로그/PASS → 보드 오실로스코프 실측을 구분한다. 실험실에서는 기본적으로 함수발생기·오실로스코프를 사용하고, 시연에 추가 장비가 정말 필요해질 때만 구매를 검토한다.

## 5. 꼭 이해해야 할 개념

- **[A]** 16 kHz 샘플 타이밍·ADC/DAC 데이터 경로, IIR Notch 차분방정식, 고정소수점/오버플로·안정성, 가변 계수 원자적 적용, 샘플 중단 없이 버퍼를 교환하는 방법.
- **[A]** SPI Slave의 양방향 데이터 교환, 명령/응답 패킷과 데이터 유효 시점, 샘플 누락·중복 검출.
- **[A]** 스톱워치 FSM, 디지털시계 달력/요일·윤년 경계조건.
- **[B]** Text LCD 구동, 핀/배선 확인, 계수 포맷과 시험 파형 읽기.
- **[C]** STM32 FFT 알고리즘의 내부 구현(분석용 결과와 인터페이스를 설명할 정도).
