## 2. HMF2525 함수발생기 — 기본 사인파 입력

1. ADC에 연결하기 전 HMF2525의 **OUTPUT을 OFF**로 두고, 기존 연결 및 ADC 아날로그 입력의 허용 전압을 확인한다.
2. 전면 패널에서 **Sine 파형 버튼**을 누른다.
3. 화면 오른쪽의 소프트키로 **Frequency**를 선택하고 숫자 키패드에서 `500` 후 `Hz` 단위 키를 입력한다 (다음 측정에서 `1`, `kHz`).
4. **Amplitude**를 선택해 필요한 `Vpp`를 설정한다. 목표 전압은 보드 아날로그 입력 규격과 전처리 회로에 따라 확정하며, 매뉴얼만 보고 임의로 3.3 V를 설정하지 않는다.
5. **Offset** 값을 설정하고, 필요하면 별도의 **OFFSET 버튼을 눌러 활성화**한다. 매뉴얼에 따르면 전원 투입 후 OFFSET과 OUTPUT은 비활성화 상태이다. 표시 화면의 offset 숫자뿐 아니라 활성 상태도 확인한다.
6. **MENU → SYSTEM**에서 부하 임피던스 표시가 실제 연결(`HIGH Z` 또는 `50 Ω`)과 맞는지 확인한다. **50 Ω으로 설정하고 High-Z 부하에 연결하면 실제 출력 진폭은 화면 표시값의 최대 약 2배**가 될 수 있다.
7. 우선 오실로스코프에 연결해 실제 Vpp, Offset 및 주파수를 확인한 뒤, ADC 아날로그 입력에 연결한다. 보호 접지/접지클립이 의도하지 않은 접점을 단락시키지 않도록 확인한다.
8. 전면의 **OUTPUT 버튼**으로 출력 ON. 활성화되면 버튼의 흰 LED가 켜진다.

근거: HMF2525 User Manual 영문 인쇄 38–40, 48–49쪽.

**시험 입력의 주파수만 미리 확정:** BYPASS/500 Hz, FIXED/500 Hz 보존, FIXED/1 kHz 억제. 전압과 오프셋의 실제 설정치는 **보드 아날로그 입력 회로 확인 후** 확정. HMF2525는 함수발생기이며 GPE-3323/E3632A의 일반적인 DC 전원 출력으로 사인파를 대체할 수 없다.

## 3. TBS2000B 오실로스코프 — W1에서 쓸 기능

### 두 채널 비교

- CH1: ADC로 실제 인가되는 **아날로그 입력**
- CH2: DAC의 실제 **아날로그 출력**
- `Autoset`은 시작점으로만 사용하고, 이후 두 파형이 화면 안에 표시되도록 수직 스케일/오프셋을 조정한다.
- 채널별 `Frequency`, `Pk-Pk`(Vpp), 필요하면 `Mean`(DC 오프셋)을 기록한다. 채널 1과 채널 2의 Vpp를 비교할 때 프로브 배율(1X/10X), 커플링 및 같은 입력 조건을 확인한다.
- 실제 아날로그 입력/출력의 접지 기준과 프로브 접지클립 연결은 보드 회로를 우선 확인한다.

### FFT (고정 Notch 검증)

- 해당 채널의 파형 여러 주기를 획득한다.
- **FFT** 버튼을 누르고 소프트 메뉴에서 **소스(CH1/CH2)**를 선택한다.
- 수직 단위는 매뉴얼에 따라 `dBV RMS` 또는 `Linear RMS` 선택 가능하다.
- 매뉴얼은 FFT 파형 표시가 **2000 또는 20K 포인트 레코드 길이**에서 지원된다고 명시한다.
- 500 Hz 보존과 1 kHz 억제 검증 시, BYPASS와 FIXED에서 **동일한 입력 진폭·주파수·측정 조건**을 유지하고 해당 성분의 FFT 크기를 비교한다.
- 일반 시간 영역의 Vpp가 줄었다는 사실만으로 1 kHz 주파수 성분의 dB 감쇠량을 확정하지 않는다. FFT 스펙트럼 혹은 정량 처리한 저장 파형 데이터를 사용한다.

근거: TBS2000B 한글 설명서 인쇄 71–72, 93–96, 116–120쪽.

### 파형/캡처를 USB로 저장하는 버튼 경로

- 화면 이미지(PNG): **USB 연결 → 저장/호출(Save/Recall) → 실행(Action) → 이미지 저장 → 파일 형식(PNG) → 저장(Save)**.
- 추후 수치 분석이 필요하면 파형 데이터를 **USB CSV**로 따로 저장한다: `저장/호출 → 실행 → 파형 저장 → 저장 위치 USB CSV → 소스 CH1 또는 CH2 → 저장`.
- 이미지와 CSV는 다르다: **PNG는 화면 스냅샷**, **CSV는 샘플 데이터**. 가능한 경우 전후 비교에는 CSV도 유용하지만, 필수 증빙을 불필요하게 늘릴 필요는 없다.

근거: TBS2000B 한글 설명서 인쇄 133–138쪽.

## 4. 멀티미터 및 DC 전원공급기

- 34460A/34461A: 필요할 때 전원/오프셋의 DC 전압을 점검하고, 연결 경로의 **연속성 측정은 반드시 회로 전원을 끈 상태**에서 수행한다.
- GPE-3323과 E3632A는 전압·전류 제한을 갖는 **DC 전원공급기**이다. 학교 FPGA 보드가 기존 전원 연결만으로 정상 동작한다면 외부 전원공급기 추가가 필수인 것은 아니다.
- 외부 전원공급기를 실제 사용할 경우 **전압/전류 제한 설정 → 극성 확인 → 회로 연결 → 출력 ON** 순서로 진행한다. 보드가 허용하지 않는 추가 전원을 연결하지 않는다.

## 6. 아직 이 매뉴얼들로 확정할 수 없는 사항

- FPGA Combo II-DLD S75 보드 **ADC 아날로그 입력 범위, 바이어스, 전압 레퍼런스, 단자 접지**
- DAC 실제 아날로그 출력 핀/부하 조건
- BDIO03/G8, J10, BD_SEL1 실제 연결 경로 및 SPI 전기적 연결
- W1 FPGA 외부 인터페이스 타이밍 사인오프
- STM32의 실제 SPI 통합 동작

이 사항들은 계측기 매뉴얼이 아니라 기존 FPGA LAB 교안, 보드 회로도, 측정 결과를 기준으로 확인한다. 이 파일은 RTL/비트스트림을 변경하지 않는다.
