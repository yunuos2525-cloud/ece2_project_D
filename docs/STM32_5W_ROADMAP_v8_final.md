# STM32 담당 5주 개발 로드맵 · v8

> 프로젝트: **FPGA–STM32 기반 미지의 단일 협대역 간섭 자동 추적·억제 시스템**  
> 담당: STM32의 **주파수 분석·추정, 필터 계수 계산, DSP 모드 제어**  
> 팀 공통 인터페이스: [`TEAM_SPI_INTERFACE_v8_final.md`](TEAM_SPI_INTERFACE_v8_final.md)

## 1. STM32가 맡는 실제 핵심 기능

**FPGA가 보내는 16 kHz·8-bit 오디오 샘플을 분석하여 미지의 단일 간섭 주파수를 알아내고, 그 주파수를 줄일 필터 계수를 FPGA에 전달한다.** 간섭 주파수가 달라지면 다시 추정하고 새 계수를 전송한다.

| 필수 기능 | 외부에서 확인할 결과 |
|---|---|
| **분석용 샘플 수신** | FPGA로부터 512개 샘플이 누락·중복 없이 전달되고 블록 번호로 구분됨 |
| **FFT 주파수 분석** | 미리 정해진 네 후보가 아니라, 시험 범위(초기 제안 **700~3,000 Hz**) 안의 미지 단일 간섭 주파수 추정 |
| **안정적인 간섭 판단** | 일시적인 잡음이나 한 번의 잘못된 값 때문에 필터가 불필요하게 바뀌지 않도록 연속 분석 결과 판단 |
| **Notch 계수 계산** | 추정 주파수에 맞는 2차 IIR 필터 계수 5개 계산·정해진 고정소수점 형식으로 변환 |
| **SPI 계수 전송** | FPGA가 완전한 계수 묶음을 받아 새 필터로 바꿀 수 있도록 보냄 |
| **DSP 모드 선택** | BYPASS / FIXED(1 kHz) / AUTO 요청을 STM32에서 전달 |
| **재추적** | 간섭이 다른 주파수로 바뀌면 재추정 → 새 계수 전송이 자동으로 진행 |

**STM32가 하지 않는 일:** 매 샘플의 IIR 연산·DAC 출력, FPGA 시계·스톱워치·Text LCD, 필터 2개 동시 제거. 사용자 수동 임계값 조절/후보 주파수 제한/상태를 PC에 장황하게 표시하는 기능은 **필수가 아니다**. 간단한 디버그 로그는 유용하지만 핵심 기능으로 만들지 않는다.

### 16 kHz 샘플을 어떻게 받나?

- STM32가 샘플을 읽으려면 FPGA 측 **MISO 송신 기능**과 양측의 샘플 블록 송수신 기능을 구현하고 함께 검증해야 한다.
- STM32가 **SPI Master**이고, 샘플을 읽을 때도 STM32가 SCK를 발생시킨다. FPGA가 마음대로 데이터를 밀어 보내는 구조가 아니다.
- 분석 초기값: **512샘플 = 32 ms 구간**. 16 kHz, 8-bit 원시 샘플 기준 블록당 512바이트. FFT 주파수 간격은 **31.25 Hz**(정확도/오차와 동일 개념은 아님).
- FPGA의 음향 출력은 STM32 FFT를 기다리지 않는다. 새 필터 계수가 준비되기 전까지 이전 유효 필터로 계속 처리한다.

## 2. 5주 개발·검증 일정

실험실 사용 시간: **주 1회 × 4시간**. 아래는 기능 목표와 검증 기준이며, C 코드 구조·라이브러리·DMA 사용 여부는 STM32 담당자가 결정한다.

| 주차 | 개발·단위 시험 | 실험실 공동 검증 | 완료 기준 |
|---|---|---|---|
| **W1 · FFT/통신 기초** | 생성한 시험 데이터(500 Hz + 미지 간섭)로 **512포인트 FFT**와 주파수 추정 기능 독립 검증. **1 kHz/미지 주파수 Notch 계수 계산** 시험. SPI Master 블록 읽기·세 DSP 모드 명령 준비 | SCK/MOSI/CS 및 **MISO 송수신 경로·전압·방향 확인**, FPGA ADC/DAC 기초 보드 시험 협력 | 정해진 배열에 대한 FFT 피크·계수 산출 결과 PASS. MISO 검증 여부·남은 블로커 기록 |
| **W2 · 제어 프로그램 완성** | 실제 FPGA 블록 번호/상태를 읽고 FFT → 간섭 추정 → 계수 전송까지 연결. 한 번의 오검출에 즉시 반응하지 않는 최소 안정화, 모드 입력, 오류/재시작 처리 검증 | FPGA의 **512샘플 블록 수신**, 새 계수 적용, FIXED/AUTO 모드 시험 | FPGA 데이터 또는 동일 형식 모의 입력으로 주파수별 추정·계수 변경 검증. 전송 실패 시 직전 유효 설정을 깨뜨리지 않음 |
| **W3 · 실물 자동 추적 완성 목표** | 데이터 블록 처리시간·통신 순서·필터 갱신 오류 수정. 시험 조건/증거 정리 | 함수발생기 간섭 주파수 변경 → STM32 재추정·재설정 → FPGA 출력을 오실로스코프로 검증 | **미지 단일 간섭의 자동 재추적·제거가 실물에서 재현**됨. 실패 시 원인 구간 특정 |
| **W4 · 정량 검증/디버깅** | 오류 수정·성능 측정 정리 중심. 신규 필수 기능 추가 금지 | 주파수 추정 오차, 재추적 시간, 송·수신 손실/재시작 시험 | FFT 추정 기록과 오실로스코프 결과를 연결해 재현성 검증 |
| **W5 · 최종 안정화** | 최소 수정, 최종 코드·증거·발표 정리 | 시연 절차 반복·결함 회귀 시험 | STM32가 재시작 후에도 자동 추정·계수 갱신을 재현 |

### 단계 판정

- **W1:** PC/MCU에 저장된 *정답이 알려진 시험 데이터*로 FFT가 동작하지 않으면, FPGA 실측 데이터 통합 전에 FFT 추정부터 수정한다. MISO 핀 검증은 공동 최우선 과제.
- **W2:** FFT 자체, 송신/수신, 가변 계수 적용을 **각각 독립 검증**한 뒤 결합한다. 서로 다른 문제를 하나의 실패로 묶지 않는다.
- **W3:** 단일 미지 간섭 실물 검증이 불안정하면 신규 기능 추가를 멈춘다.
- **W4~W5:** 신규 필수 기능 추가 없이 원인 분석과 기존 기능 재검증에 집중한다.

## 3. 최소 기술 합의(코드 작성 전에 확인)

- **SPI:** STM32 Master / FPGA Slave, Mode 0, MSB first. SCK/MOSI/CS 배선 유지. **MISO 핀 배정: STM32 PA6(D12/CN5-5) ↔ FPGA BDIO03(G8). FPGA 패키지 핀 대응은 실습 장비 교재 핀 구성표 확인. 실제 J10 연결·BD_SEL1 설정 및 3.3 V 신호 경로는 보드 시험으로 확인.** 상세 프레임은 `TEAM_SPI_INTERFACE_v8_final.md`.
- **오디오:** 16,000 samples/s, mono, unsigned 8-bit. FFT 전 DC 성분을 제거하거나 적절히 처리한다. 원본 오디오를 FPGA가 처리하므로 STM32가 DAC용 샘플을 다시 보내지 않는다.
- **FFT:** 초기 512포인트, 주파수 간격 **31.25 Hz**. 500 Hz 정상 시험 신호를 제거 대상에서 구분하기 위해, 초기 간섭 탐색은 **700~3,000 Hz** 범위에서 수행하는 것으로 제안한다. 신호가 약할 때 오검출하지 않도록 최소 기준을 둔다(사용자에게 조절 UI를 제공할 필요 없음).
- **간섭:** 한 번에 **협대역 톤 1개**라는 시험 조건. 주파수 변경 후 재추적 시험. FFT의 최대 피크가 항상 간섭은 아니므로 신호/잡음 수준 조건도 시험 기록에 명시한다.
- **계수:** STM32가 `b0, b1, b2, a1, a2`를 계산하고 **signed Q2.14, little-endian**으로 전달. FPGA의 차분방정식과 부호 정의는 공통 규격에 고정한다. 잘못된 값, 비정상 부동소수점, 범위 초과를 송신 전에 확인한다.
- **제어:** BYPASS=`0x01`, FIXED=`0x02`, AUTO=`0x06`. `CLEAR_ERROR=0x05`는 선택적 진단 플래그 초기화 명령으로 예약한다.

## 4. 조원이 직접 입증할 시험

| 입력 조건 | STM32 예상 출력과 확인 근거 |
|---|---|
| 모의 **1,370 Hz** 톤 | 512포인트 FFT에서 근처 피크 검출. 정확한 오차는 시험 후 수치로 기록 |
| 모의 **1,830 Hz** 톤 | 새로운 주파수로 재추정하고 필터 계수 변경 |
| 500 Hz 단독 입력 | 정상 신호를 간섭이라고 판단하지 않고 불필요한 Notch 설정을 반복하지 않음 |
| 500 Hz + 미지 단일 간섭 | 정해진 탐색 범위에서 간섭을 찾고 그 주파수의 계수 전송 |
| 중복 샘플 블록/전송 오류 | 블록 번호·길이 확인, 이전 유효 필터를 깨지 않도록 동작 |
| 주파수 930 → 2,460 Hz 전환 | 재추정 → 설정 갱신 로그 및 실제 보드 출력 확인 |
| STM32 재시작/통신 일시 중단 | FPGA 오디오는 끊기지 않고, 재연결 후 설정 동기화 |

**측정 목표(성과 주장 아님):** FPGA 출력 간섭 감쇠 ≥10 dB, 정상 성분 오차 ≤1 dB, 입력→출력 처리 지연 ≤20 ms. STM32 쪽에서는 **주파수 추정 오차, FFT 처리시간, 주파수 변경 후 재추적 시간**을 별도로 기록한다.

**검증 장비 원칙:** 개발 중 학교 함수발생기와 오실로스코프 중심. 시연에 추가 장비가 실제 필요한 경우에만 구매 검토.

## 5. 학습 우선순위

- **[A]** 샘플링·FFT의 의미/주파수 간격, 스펙트럼에서 간섭 주파수 찾기, C 배열·정수/실수·함수, 2차 IIR Notch 계수와 FFT 추정 오차의 관계.
- **[A]** SPI Master의 송신/수신 타이밍과 데이터 블록 관리, 전송 오류 감지, 재추정 시점·필터 변경 정책.
- **[B]** CMSIS-DSP 등 라이브러리 활용(선택), UART 디버그 로그, 빌드/디버깅·실측 자료 정리.
- **[C]** FPGA 필터 내부 RTL, LCD/시계 구현 세부.
